# 🖼️ ImgReader — อ่านภาพทั้งโฟลเดอร์แบบเลื่อนต่อเนื่อง

SPA ไฟล์เดียว (`index.html`) เปิดด้วยการ **ดับเบิลคลิก** ได้เลย — ไม่ต้องติดตั้ง ไม่ต้องรัน server
ภาพทุกไฟล์ในโฟลเดอร์จะเรียงจากบนลงล่าง เต็มความกว้าง เลื่อนอ่านต่อเนื่อง
และมี **ชื่อไฟล์คั่นระหว่างภาพ** ทุกภาพ

## 🌐 เปิดจากเว็บ (ใช้ได้ทุกเครื่อง ไม่ต้องก๊อปไฟล์)

**<https://witchupang.github.io/imgreader/>**

- **ภาพไม่ได้ถูกอัปโหลดไปไหนทั้งสิ้น** — หน้าเว็บอ่านไฟล์จากดิสก์ผ่าน File API ในเบราว์เซอร์ล้วน ๆ
  ไม่มีการส่งข้อมูลออกนอกเครื่อง (หน้านี้เป็น static HTML ไฟล์เดียว ไม่มี server ไม่มี script ภายนอก)
- เปิดจาก `https://` ดีกว่าเปิดไฟล์ในเครื่องด้วยซ้ำ เพราะเป็น secure context เต็มตัว →
  `showDirectoryPicker()` ใช้ได้แน่นอน ปุ่ม 💾 จึงเขียน `index.html` ลงโฟลเดอร์ภาพได้ตรง ๆ
  (บน `file://` เบราว์เซอร์บล็อก API นี้บ่อย)
- ค่าที่จำไว้ (ธีม/โหมด/%) แยกกันคนละชุดกับตัวที่เปิดจากไฟล์ในเครื่อง เพราะ localStorage ผูกกับ origin
- อัปเดตเว็บหลังแก้โค้ด: รัน `publish.ps1` ในโฟลเดอร์นี้ (โฟลเดอร์นี้คือต้นฉบับเดียว ไม่มี clone ที่สอง)

## วิธีใช้ (ในเครื่อง)

1. ดับเบิลคลิก `index.html` (หรือ `เปิด ImgReader.bat`)
2. กด **📂 เลือกโฟลเดอร์** แล้วเลือกโฟลเดอร์ที่มีภาพ (เบราว์เซอร์จะถามยืนยัน "อัปโหลด" = แค่อ่านในเครื่อง ไม่มีการส่งออกไปไหน)
   หรือจะ **ลากโฟลเดอร์มาวางบนหน้า** ก็ได้
3. เลื่อนอ่านได้เลย

นามสกุลที่อ่าน: `jpg jpeg png gif webp avif bmp jfif ico svg`

### 🗂️ รวมโฟลเดอร์ย่อยหรือไม่

ปุ่มบนแถบบน (หรือกด `B`) สลับได้ 2 แบบ — **จำค่าไว้** และมีผลกับการเปิดครั้งต่อไปด้วย

| ปุ่ม | ความหมาย |
|---|---|
| **🗂️ ย่อย** (ค่าเริ่มต้น) | อ่านภาพในโฟลเดอร์ย่อยทั้งหมดด้วย แยกกลุ่มตามโฟลเดอร์ในแถบรายชื่อไฟล์ |
| **📁 ชั้นเดียว** | เอาเฉพาะไฟล์ภาพที่อยู่ในโฟลเดอร์ที่เลือกโดยตรง ไม่ลงไปในโฟลเดอร์ย่อย |

- **สลับได้ทันทีหลังเปิดโฟลเดอร์แล้ว** ไม่ต้องเลือกโฟลเดอร์ใหม่ (เก็บรายการดิบไว้แล้วกรองเอา)
- เปิดโฟลเดอร์ตอนอยู่โหมด **ชั้นเดียว** แล้วโฟลเดอร์นั้นมีของอยู่ข้างล่าง จะขึ้น**แถบชวนที่มุมล่าง**
  ("ยังมีภาพในโฟลเดอร์ย่อยอีก N ภาพ" → กด **🗂️ รวมโฟลเดอร์ย่อยด้วย**) ไม่ต้องเดาก่อนเปิด
- ถ้าชั้นบนสุด**ไม่มีภาพเลย** แต่มีโฟลเดอร์ย่อย จะเปิด "รวมย่อย" ให้อัตโนมัติ (ไม่เปิดมาโล่ง ๆ)
- ถ้าเปิดโฟลเดอร์แบบ "ชั้นเดียว" ไว้ แล้วมาสลับเป็น "ย่อย" ทีหลัง จะไล่อ่านโฟลเดอร์ย่อยเพิ่มให้เอง
  (โหมดชั้นเดียวไม่ไล่เข้าโฟลเดอร์ย่อยตั้งแต่แรก จึงเปิดโฟลเดอร์ใหญ่ ๆ ได้เร็วกว่ามาก)

> **⚠ "ชั้นเดียว" จะเร็วจริงเฉพาะตอนได้ handle ของโฟลเดอร์** คือเปิดด้วย `showDirectoryPicker()`
> หรือลากโฟลเดอร์มาวาง ซึ่งเราสั่งไม่ให้ไล่เข้าโฟลเดอร์ย่อยได้
> ถ้าตกไปใช้โหมดสำรอง `<input webkitdirectory>` (เกิดบ่อยตอนเปิดจากไฟล์ `file://` เพราะ Chrome
> บล็อก File System Access API) **เบราว์เซอร์จะสแกนทั้งต้นไม้ให้ก่อนเสมอ หยุดไม่ได้** ตัวเลือกนี้
> จะมีผลแค่ตอนแสดงผล → **เปิดผ่าน <https://witchupang.github.io/imgreader/> จะได้ทางเร็วเสมอ**
- ปุ่ม 💾 สร้าง HTML จะฝังเฉพาะรายการที่กำลังแสดงอยู่ — เลือกโหมดให้ตรงก่อนกดสร้าง

## 💾 สร้าง index.html ไว้ในโฟลเดอร์ภาพ (เปิดแล้วอ่านได้เลย)

เปิดโฟลเดอร์แล้วกดปุ่ม **💾 สร้าง HTML** บนแถบบน → ได้ไฟล์ `index.html` ที่เป็น
**ตัวโปรแกรมทั้งตัว + รายชื่อไฟล์ภาพฝังไว้ข้างใน** (อ้างภาพแบบ relative path)

1. กด **📂 เปิดโฟลเดอร์** (เบราว์เซอร์จะถามสิทธิ์ "ดูและแก้ไขไฟล์" ในโฟลเดอร์นั้น — กดอนุญาต)
2. กด **💾 สร้าง HTML** → ยืนยัน
3. ไฟล์ `index.html` จะถูก**เขียนลงในโฟลเดอร์ภาพนั้นเลย** ไม่มีกล่อง "บันทึกเป็น" ให้หลงโฟลเดอร์
4. ดับเบิลคลิก `index.html` นั้น = เห็นภาพทั้งโฟลเดอร์ทันที ไม่ต้องกดเลือกโฟลเดอร์อีก

- เขียนตรงได้เพราะตอนเปิดโฟลเดอร์ใช้ `showDirectoryPicker()` ซึ่งให้ **handle ของโฟลเดอร์** มาด้วย
  (ลากโฟลเดอร์มาวางก็ได้ handle เหมือนกัน ผ่าน `getAsFileSystemHandle()`)
- ถ้าเบราว์เซอร์ไม่รองรับ จะถอยไปใช้วิธีเดิม (เลือกโฟลเดอร์แบบ `webkitdirectory`) ซึ่ง **เว็บไม่มีทางรู้ path เต็มของโฟลเดอร์**
  กรณีนี้ 💾 จะเปิดกล่องบันทึก/ดาวน์โหลดแทน แล้วต้องย้ายไฟล์ไปไว้ในโฟลเดอร์ภาพเอง
  (⚠ ระวังอย่าบันทึกทับ `index.html` ของตัว ImgReader เอง)
- ไฟล์ที่สร้างมีฟีเจอร์ครบเหมือนตัวหลักทุกอย่าง (โหมด/ซูม/แถบชื่อไฟล์/คีย์ลัด) แต่ซ่อนปุ่ม 💾 ไว้
- ถ้าเพิ่ม/ลบภาพในโฟลเดอร์ทีหลัง ต้องกดสร้างใหม่ทับ (รายชื่อไฟล์ถูกฝังไว้ตั้งแต่ตอนสร้าง)
- ย้ายทั้งโฟลเดอร์ไปไหนก็ยังใช้ได้ เพราะอ้างภาพแบบ relative

## โหมดแสดงภาพ (เลือกจาก dropdown บนแถบ หรือกด `1` `2` `3` / `M` สลับ)

| โหมด | ทำอะไร |
|---|---|
| `1` ↔ **พอดีความกว้าง** | ภาพยืดเต็มความกว้างคอลัมน์ (ค่าเริ่มต้น) — สไลเดอร์ = % ของความกว้างจอ, **20–100%** |
| `2` **1:1 ขนาดจริง** | ภาพขนาดพิกเซลจริง ไม่ย่อไม่ขยาย กว้างเกินจอก็เลื่อนซ้าย-ขวาได้ — สไลเดอร์ = ซูมจากขนาดจริง (100% = 1:1), **10–400%** |
| `3` ↕ **พอดีความสูง** | 1 ภาพ = 1 หน้าจอพอดี (กด `J`/`K` เปลี่ยนภาพเหมือนพลิกหน้า) — สไลเดอร์ = % ของความสูงจอ, **20–100%** |

- **โหมด "พอดี" สไลเดอร์สูงสุด 100%** โดยตั้งใจ — เกิน 100% แล้วมันไม่พอดีอีกต่อไป (ภาพล้นจอ) ถ้าอยากซูมเกินจอให้สลับไปโหมด **ขนาดจริง** ซึ่งซูมได้ถึง 400%
- ปุ่ม **`−` / `+`** ข้างสไลเดอร์ = ย่อ/ขยาย **ทีละ 10%** (ปัดให้ลงตัวสิบเสมอ เช่น 55 → 60 → 70) เท่ากับกดคีย์ `−` / `+` · ปุ่มจะจางเมื่อชนเพดานของโหมดนั้น
- ปุ่ม **`⟲ 100%`** = รีเซ็ตกลับ 100% (เท่ากับกด `0`) · จางเมื่ออยู่ที่ 100% อยู่แล้ว
- **% แยกของแต่ละโหมด** — สลับโหมดแล้วตัวเลข % จะเปลี่ยนเป็นค่าของโหมดนั้น (เริ่มต้น 100% ทุกโหมด = ขนาดจริง 1:1 / เต็มความกว้าง / เต็มความสูง) ไม่มีการเอา % ของอีกโหมดมาปนอีก
- เปลี่ยนโหมด/ซูมแล้วหน้าจะตรึงอยู่ที่ภาพเดิม ไม่เด้งกลับไปข้างบน
- **ภาพที่ซูมจนกว้างเกินจอ**: หน้าจะเลื่อนแนวนอนตามให้เอง (ภาพกว้างกว่าจอ = ชิดขอบซ้ายของภาพ, แคบกว่าจอ = กึ่งกลาง) และ **ลากด้วยเมาส์เพื่อเลื่อนดูได้** (เคอร์เซอร์เป็นรูปมือ) หรือใช้ลูกศรซ้าย/ขวา

## ปุ่ม / ทางลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `1` / `2` / `3` / `M` | โหมดแสดงภาพ (ตามตารางบน) |
| `+` / `−` / `0` | ขยาย / ย่อ / รีเซ็ต 100% |
| `J` / `N` | ภาพถัดไป |
| `K` / `P` | ภาพก่อนหน้า |
| `Home` / `End` | ภาพแรก / ภาพสุดท้าย |
| `B` | สลับ รวมโฟลเดอร์ย่อย / เฉพาะชั้นบนสุด |
| `S` | เปิด-ปิดแถบรายชื่อไฟล์ (คลิกชื่อ = กระโดดไปภาพนั้น) |
| `C` | ซ่อน/แสดงแถบชื่อไฟล์ใต้ภาพ |
| `T` | สลับธีมมืด/สว่าง |
| `H` | ซ่อน UI ทั้งหมด (อ่านเต็มจอสะอาด ๆ) |
| `F` | เต็มจอ |
| `O` | เลือกโฟลเดอร์ใหม่ |

> คีย์ลัดทั้งหมด **ใช้ได้ทั้งตอนแป้นพิมพ์เป็นไทยและอังกฤษ** — อ่านจาก `event.code`
> (ตำแหน่งปุ่มจริงบนแป้น) ไม่ใช่ตัวอักษรที่พิมพ์ออกมา จึงไม่ต้องคอยสลับภาษาก่อนกด

- ปุ่ม `⧉` ท้ายแถบชื่อไฟล์ = คัดลอกชื่อไฟล์
- ช่องเรียง: ชื่อไฟล์แบบ natural (1, 2, 10 ไม่ใช่ 1, 10, 2) / ย้อนกลับ / วันที่แก้ไข / ขนาดไฟล์
- ค่าที่ตั้งไว้ (ความกว้าง ธีม ชื่อไฟล์ แถบข้าง) จำไว้ใน localStorage

## หมายเหตุทางเทคนิค

- ภาพโหลดแบบ lazy: สร้าง object URL เมื่อใกล้จอ (`1800px`) และ **คืนหน่วยความจำเมื่อเลื่อนห่างเกิน `4000px`**
  → เปิดโฟลเดอร์เป็นพันภาพก็ไม่กินแรม (จำอัตราส่วนภาพไว้ ความสูงจึงไม่กระตุก)
- ไฟล์ไม่ถูกคัดลอกหรือส่งขึ้นเน็ต — อ่านผ่าน File API ในเครื่องล้วน ๆ
- ใช้ `webkitdirectory` + drag-drop แทน File System Access API เพราะ API ตัวหลังใช้กับ `file://` ไม่ได้
